# Board glitches

Jak II's board has glitches that speedrunners use. The mod runs the same code, so they stay.
Nothing here is patched out. If one behaves differently from Jak II, that is a bug in the port.

Sources: the [Jak speedrun wiki](https://wiki.jakspeedruns.com/Jetboard) and community guides.

| Glitch | How to do it (Jak II buttons) | What happens |
|---|---|---|
| Hover | In one jump, cancel a side trick into an up or down trick, then into another; keep a steady rhythm | Endless height and air time |
| Extended front flip | Do an up or down trick, then cancel into a front flip | A long jump |
| Free fall | Mash Cross as a hover ends | Steer the board while falling |
| Sideflip | Spin 360 and end facing forward, holding up | A side flip that sets up a hover |
| Stationary hover | Press Cross, then the board button, standing still | A quick hover with no speed |
| Turn hover | Start a hover at an angle with the stick centred | A hover that turns |
| High jump | Hold the duck button while jumping | A higher jump |

The buttons here are Jak II's names: the duck button is L2 by default and the trick button R1 (or R2). See the controls in the README.

## Not in Ratchet & Clank

Skips that rely on Jak II's levels, loading or story (tomb skips, race shortcuts) have no place here.
